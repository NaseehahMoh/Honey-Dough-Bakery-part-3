# Changelog

All notable changes made to the Honey Dough Bakery website are documented below.

## Version 1.0 – Initial website
- Created the Home, About Us, Menu, Order and Contact pages.
- Added the original external CSS stylesheet and bakery colour palette.
- Added navigation, product cards, buttons, an order form and a contact form.
- Added responsive layouts for tablet and mobile screens.

## Version 1.1 – Part 3 improvements
- Kept the original cream, peach, cocoa brown and terracotta colour palette.
- Standardised file names to lowercase so links work consistently on hosting platforms.
- Added page-specific title tags, meta descriptions and keywords.
- Added descriptive image file names and alternative text.
- Added an image gallery with a lightbox.
- Added an interactive map for Pietermaritzburg using Leaflet and OpenStreetMap.
- Added product search and alphabetical sorting to the Menu page.
- Added an Enquiry page as required by the project brief.
- Improved order and contact forms with appropriate fields and validation.
- Added JavaScript feedback and email preparation for forms.
- Added `robots.txt` and `sitemap.xml`.
- Updated the README and references.

## Notes
- Forms prepare an email in the visitor's email application. A backend or email service is required for automatic website-based email delivery.
- The sitemap and robots file contain placeholder GitHub Pages addresses that must be updated after deployment.
